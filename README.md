# 12주차 성적 데이터 분석

## 데이터 출처

실습용 `scores_2026.csv`를 사용했습니다. `mini.csv`는 정제와 평균 계산을 확인하는 테스트용 데이터입니다. GitHub에 게시하는 CSV 사본에서는 학번과 이름을 익명화했습니다.

## 행 수

헤더를 제외한 데이터 행 기준입니다. 원본은 114행이고 정제 후 100행이 남았습니다. 점수가 빈 6행, 완전히 같은 중복 행 4행, 0~100 범위를 벗어난 점수 4행을 제외했습니다. 반과 과목의 앞뒤 공백도 제거했습니다.

## 열 설명

- 학번: 학생 식별용 문자값(게시용 데이터에서는 익명화)
- - 이름: 학생 이름(게시용 데이터에서는 익명화)
  - - 반: 학생이 속한 반
    - - 과목: 점수를 받은 과목
      - - 점수: 해당 과목의 점수(0~100점)
